## Стан, старт, крок (Завдання 3)

**Сума**

**Добуток**

**Максимум**

## Пояснення захоплення змінних (Завдання 5)

1. **Змінна після лямбди.** Для числа 4 результат змінюється з `True` на `False` після присвоєння `threshold = 1000`. Лямбда захоплює змінну, а не знімок її початкового значення 3. Під час виклику вона читає вже новий поріг.
2. **Цикл for.** Фактичний вивід: `3, 3, 3`. Усі три лямбди захопили одну змінну `i`; коли цикл завершився, вона мала значення 3. Виклики відбуваються після циклу, а не в момент додавання лямбд.
3. **Цикл foreach.** Фактичний вивід: `0, 1, 2`. У сучасному C# кожна ітерація `foreach` має окрему змінну ітерації, тому кожна лямбда захоплює своє значення.

Виправлення `for`: усередині циклу створити `int copy = i;` і захоплювати `copy`; перевірений вивід — `0, 1, 2`.
