| Вхід | Завдання | Очікувано | Отримано |
| :--- | :--- | :--- | :--- |
| **Порожній масив** (`length = 0`) | 1–4 | Коректне повідомлення про те, що результат не визначений, без винятків | Програма перевіряє `arr.Length == 0`, виводить повідомлення і завершує метод без аварійного падіння. |
| **Один елемент** (`length = 1`) | 1–4 | Сума дорівнює елементу, мін/макс дорівнюють цьому елементу, серія довжиною 1, зсув залишає масив без змін | Алгоритми опрацьовують цикл коректно, індекси не виходять за межі (`IndexOutOfRangeException` відсутній). |
| **Усі елементи однакові** | 1, 3 | Мінімум і максимум знайдено правильно, найдовша серія дорівнює довжині всього масиву | Змінна `currentLength` успішно охоплює весь масив, індекс початку серії дорівнює `0`. |
